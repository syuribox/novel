    メモ

    いろいろなruby

    プログラミング言語げんごRuby、htmlのルビ要素ようそruby、そして宝石ほうせきのrubyが最低さいていでもあります。技術ぎじゅつ系けいサイトではプログラミング言語げんごと混まざってしまい情報検索じょうほうけんさくが面倒めんどうです。

    HTML ruby 改行かいぎょう

    rubyタグはChromeでは限界げんかいを超こえると改行かいぎょうする措置そちがあります。一方いっぽう、Firefox、Safariでは改行かいぎょうされず右側みぎがわ(下側したがわ)にはみ出でます。(参考さんこう)

    HTML ruby 同一どういつルビ

    rubyタグはFirefoxでは、ルビ親おやとルビテキストが同一どういつのとき、ルビを表示ひょうじしません。

    小説家しょうせつかになろうのルビ表記ひょうき

    文字もじ数すう制限せいげんや非常ひじょうに細こまかい独自どくじルールが大量たいりょうにあり、すべてを再現さいげんする完全かんぜん互換ごかんはかなり難むずかしいです。
