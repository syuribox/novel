マハム・ハインリヒ

6歳さい / ハインリヒ侯爵こうしゃく家け三男さんなん / スキル：スローライフ

5歳さいの鑑定かんていの儀ぎで「スローライフ」というハズレスキルを引ひき、両親りょうしんを落胆らくたんさせた貴族きぞく三男さんなん。6歳さいで妹いもうとミリアとともに辺境へんきょうカーマイン村むらへ領主りょうしゅ代行だいこうとして左遷させんされる。

村むらに入はいった瞬間しゅんかんスキルが活性化かっせいかし、鑑定かんてい初級しょきゅう・アイテムボックス小しょう・植物しょくぶつ図鑑ずかん知識ちしき初級しょきゅう・魔物まもの図鑑ずかん知識ちしき初級しょきゅうなどの便利べんりな派生はせいスキルを得える。戦闘せんとうよりも庭にわいじりや観察かんさつが得意とくいで、のんびり屋や。

前世ぜんせの記憶きおくを持もちながらも、村むらの人々ひとびとと関かかわり、庭にわの手入ていれやスライム狩がり、村むらの施設しせつ視察しさつを通つうじて少すこしずつ「何なにもしない」ことの奥深おくぶかさを知しっていく。転生てんせい者しゃらしい冷静れいせいさと、子供こどもらしい好奇心こうきしんを併あわせ持もつ主人公しゅじんこう。

ミリア・ハインリヒ

5歳さい / マハムの妹いもうと / スキル：裁縫さいほう

マハムの一ひとつ下したの妹いもうと。鑑定かんていの儀ぎで「裁縫さいほう」を引ひき、武勲ぶくん第一だいいち主義しゅぎの侯爵こうしゃく家けでは不満ふまんを持もたれたが、本人ほんにんはすぐに立たち直なおる優やさしい性格せいかく。

魔法陣まほうじんの刺繍ししゅうができる実用品じつようひんとしての裁縫さいほうスキルを持もち、護符ごふ作づくりが上手じょうず。村むらに来きてからはシータと一緒いっしょに針仕事はりしごとをしたり、マハムを心配しんぱいしたりと、兄あに想おもいの可愛かわいい妹いもうととして活躍かつやくする。

少すこし心配性しんぱいしょうだが、好奇心こうきしん旺盛おうせいで村むらの生活せいかつにもすぐ慣なれる。絵日記えにっきを書かくのが得意とくいで、兄上あにうえへの手紙てがみにも絵日記えにっきを添そえる。

シータ・エルドラン

16歳さい / メイド / スキル：氷こおり魔法まほう / 男爵だんしゃく令嬢れいじょう

ハインリヒ侯爵こうしゃく家けのメイドで、マハムとミリアの世話せわ係がかり。下級かきゅう貴族きぞくの親戚しんせき筋すじで、社交しゃこう界かいの噂うわさを嫌きらってメイドの道みちを選えらんだ黒髪くろかみ黒目くろめの低てい身長しんちょう巨乳きょにゅう美少女びしょうじょ。

氷こおり魔法まほう（水みず魔法まほうの上位じょうい）を持もち、生活せいかつ魔法まほうも得意とくい。クリーン魔法まほうで家いえを掃除そうじしたり、氷こおりでアイスティーやアイスクリームを作つくったりと、村むら生活せいかつを支ささえる頼たよれるお姉ねえさん。

戦闘せんとう能力のうりょくも一定いってい以上いじょうあり、護衛ごえいとしての役割やくわりも期待きたいされていた。マハムたちにとっては親代おやがわりのような存在そんざいで、優やさしくしっかりした性格せいかく。

ターリャ

6歳さい / 村長そんちょうの娘むすめ / 元気げんきな村むら娘むすめ

カーマイン村むらの村長そんちょうドーサンとカイラの娘むすめ。金髪きんぱつ碧眼へきがんの元気げんきいっぱいな女おんなの子こで、毎朝まいあさ領主りょうしゅ館かんの丘おかを駆かけ上あがって「あーそーぼー」とマハムたちを呼よびに来くる。

かけっこが得意とくいで足あしが速はやく、村むらの案内あんない役やくとしてマハムたちを連つれ回まわす。食くいしん坊ぼでお祭まつりや宴会えんかいが大好だいすき。ミリアとはすぐに仲良なかよくなる。

無邪気むじゃきで行動こうどう力りょくがあり、時ときに大人おとなを振ふり回まわすが、村むらの日常にちじょうに欠かかせない存在そんざい。マハムにとっては最初さいしょの村むらの友達ともだち。

ハインリヒ侯爵こうしゃく家け

カイン・ハインリヒ

10歳さい / 長男ちょうなん / スキル：剣術けんじゅつ

家督かとくを継つぐ予定よていの優秀ゆうしゅうな長男ちょうなん。筆ふでまめで、定期的ていきてきにマハムたちへ手紙てがみを送おくる。王都おうとでのパーティーや婚約こんやく探さがしに苦労くろうしている。

エイド・ハインリヒ

8歳さい / 次男じなん / スキル：火ひ魔法まほう

火ひ魔法まほうスキル持もちのやんちゃな次男じなん。マハムたちにはあまり興味きょうみがなく、手てに余あまる存在そんざいとして描えがかれる。

ハインリヒ侯爵こうしゃく

父親ちちおや

武勲ぶくん第一だいいち主義しゅぎの侯爵こうしゃく。ハズレスキルのマハムとミリアを左遷させんするが、一年いちねん後ごには寂さびしさを感かんじて帰還きかんを促うながす不器用ぶきような父親ちちおや。

エメダ・ハインリヒ

母親ははおや

左遷させんには反対はんたいしつつも、侯爵こうしゃく家けの事情じじょうに従したがう。子供こどもたちを気遣きづかう優やさしい性格せいかく。

カーマイン村むらの主おもな住人じゅうにん

トール

8歳さい / ガキ大将だいしょう

カーマイン村むらのガキ大将だいしょう。いばりんぼで噂うわさ好ずき、少すこし生意気なまいきな態度たいどを取とるが根ねは悪わるくない。マハムたちが村むらに来きてからはよく絡からんできて、一緒いっしょに遊あそびや探索たんさくに加くわわる。

彼女かのじょのソラエナとは幼馴染おさななじみで、彼女かのじょの前まえでは少すこし素直すなおになる。騎士きしになりたいと一時的いちじてきに木剣ぼっけんで素振すぶりをしたり、噂うわさを仕入しいれてきてはマハムたちを巻まき込こむなど、行動力こうどうりょくはあるが三日坊主みっかぼうず気味ぎみ。

村むらの子供こどもたちの中心的ちゅうしんてき存在そんざいで、マークやロイドといった兄弟きょうだいを従したがえている。マハムにとっては最初さいしょの男友達おとこともだち的てきな存在そんざい。

ソラエナ

8歳さい / トールの幼馴染おさななじみ

トールの幼馴染おさななじみで彼女かのじょポジ。頭あたまが良よく、冷静れいせいで優やさしい性格せいかく。トールが暴走ぼうそうしそうなときにさりげなく止とめる役割やくわりを担になうことが多おおい。

実じつは妖精ようせいを見みたことがあるなど、ロマンチックな一面いちめんも持もつ。マハムやミリアともすぐに打うち解とけ、村むらの子供こどもたちの中なかでは比較的ひかくてき落おち着ついた存在そんざい。

トールを支ささえるしっかり者もので、彼女かのじょの存在そんざいがあるからこそトールのガキ大将だいしょうぶりも成なり立たっている。

ラーミア

20歳さい / 猫ねこ獣人じゅうじん / 冒険者ぼうけんしゃギルド受付嬢うけつけじょう

黒髪くろかみ金目きんめの猫ねこ獣人じゅうじんで、カーマイン村むらの冒険者ぼうけんしゃギルド受付嬢うけつけじょう。語尾ごびが「にょ」という特徴的とくちょうてきな口調くちょう。口癖くちぐせが抜ぬけずに左遷させんされてきた経緯けいいを持もつ。

愛嬌あいきょうがあり、尻尾しっぽや耳みみで感情かんじょうがよく出でる。ギルドの仕事しごとはあまり忙いそがしくないため、マハムたちがスライム魔核まかくを売うりに来くるたびに会話かいわを楽たのしむ。お酒さけに弱よわく、祭まつりではよく酔よっ払ぱらう。

とある紳士しんしに好意こういを抱いだいているなど、恋愛れんあい面めんでも少すこし恥はずかしがり屋や。村むらのムードメーカー的てき存在そんざいで、マハムたちとも気軽きがるに話はなせるお姉ねえさん。

ドーサン村長そんちょう

42歳さい / 村長そんちょう

ターリャの父親ちちおや。温あたたかく世話焼せわやきで、村むらのまとめ役やく。昔むかしはガキ大将だいしょうだったという過去かこを持もつ。シイタケと紅茶こうちゃ栽培さいばいをしている。

カイラ

38歳さい / 村長そんちょうの妻つま

ターリャの母親ははおや。おっとりしているが夫おっとの尻しりを叩たたくこともある。シータにダイエット相談そうだんをするなど、村むらの主婦しゅふ代表だいひょう。

リリー・カサンドラ

見みた目め70歳さい・実じつ年齢ねんれい300歳さい以上いじょう / ハイエルフ

村むらの最長さいちょう老ろう兼けん相談そうだん役やく。最上級さいじょうきゅうポーションを製造せいぞうして村むらの外貨がいかを稼かせぐ薬師くすし。マハムの錬金術れんきんじゅつの師匠ししょう。くすんだ金髪きんぱつのハイエルフ。

バハト・ローリン準じゅん男爵だんしゃく

50歳さい / 冒険者ぼうけんしゃギルド長ちょう

普段ふだん何なにをしているか不明ふめいなギルド長ちょう。奥おくで書類しょるい仕事しごとをしているらしいが、実じつは意外いがいな趣味しゅみの副業ふくぎょうも。

ヘルマート・フィランド男爵だんしゃく

45歳さい / 商人しょうにん

村むらに来くる商人しょうにん貴族きぞく。アイテムボックス持もちで、リリーのポーションを王都おうとまで運はこぶ重要じゅうよう任務にんむを担当たんとう。丸顔まるがおで愛嬌あいきょうのある人ひと。

アンドリュー神父しんぷ

トカリアーナ教会きょうかい・カーマイン村むら出張所しゅっちょうしょ

村むらの教会きょうかいの神父しんぷ。高齢こうれいで背せが低ひくく、ドワーフ族ぞくかもしれない。熱心ねっしんな信者しんじゃで、村むらの行事ぎょうじにも積極的せっきょくてきに関かかわる。

雑貨ざっか屋やの店主てんしゅ

高齢こうれいの男性だんせい / ハゲ頭あたま

村むらの生命せいめい線せんである何なんでも屋やの店主てんしゅ。元もと鍛冶かじ屋やで金物かなものに強つよい。蜂蜜はちみつ飴あめや野沢菜のざわな饅頭まんじゅうなども扱あつかう。

喫茶店きっさてんのメイドさん

「森もりの小鳥ことりたち」ウエイトレス

村むらの喫茶店きっさてんで働はたらく素朴そぼくな村むら娘むすめのメイドさん。コーヒーやホットケーキを提供ていきょうし、マハムたちを迎むかえる。

漬物つけもの屋やのおじさん

長身ちょうしんのおじさん

村むら唯一ゆいいつの漬物つけもの専門店せんもんてんの店主てんしゅ。がっちり体型たいけいで高こう身長しんちょう。キャベツや野沢菜のざわなの漬物つけものを作つくり、町まちへも輸出ゆしゅつしている。
